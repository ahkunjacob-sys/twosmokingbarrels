# Two Smoking Barrels

Website for **Two Smoking Barrels**, a film and music atelier founded by filmmaker Roddick Vincent and composer Ricky Reji.

Instagram: [@twosmokingbarrels.co](https://www.instagram.com/twosmokingbarrels.co/)

## Files

- `index.html`: the whole site (layout, styles and scripts in one file)
- `dirt-poster.jpg`, `dirt-still.jpg`: artwork for *DIRT*
- `still-*.jpg`: film stills (`-t` files are the smaller thumbnails)
- `favicon.svg`, `favicon.ico`, `apple-touch-icon.png`: browser tab and home-screen icons
- `og-image.png`: the preview card shown when the link is shared

If the site moves to its own domain, update the `og:url` and `og:image` addresses in `index.html`.

## Publishing with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to *Deploy from a branch*.
3. Pick the `main` branch and the `/ (root)` folder, then save.

The site will be live at `https://ahkunjacob-sys.github.io/twosmokingbarrels/` after a minute or two.
